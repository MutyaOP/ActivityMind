# ActivityMind Desktop Agent

Небольшая программа для Windows: раз в несколько секунд смотрит, какое приложение активно, собирает это в сессии и отправляет на сайт ActivityMind. Данные попадают на страницу **«Активность»** (текущий сеанс и история по дням), в аналитику и в AI-модуль.

- Python 3.9+; `requests` для связи с сайтом, `pystray` и `Pillow` для значка в трее (сбор данных — на стандартном `ctypes`)
- значок в трее: **пауза и продолжение мониторинга**, выход
- локальный буфер SQLite: без сети данные не теряются и уходят позже
- вторую копию агента запустить нельзя — время не задвоится
- приватность по умолчанию: заголовки окон программ не отправляются; у браузера уходит только **категория вкладки**, а её название — лишь если на вкладке провели от 5 минут

## Установка
1. На сайте: **Устройства → Создать и получить токен** (токен показывается один раз).
2. В этой папке:
   ```bash
   pip install -r requirements.txt
   copy config.example.ini config.ini
   ```
3. В `config.ini` впишите `url` сайта (например, `http://localhost:8000`) и `token`.
4. Проверка связи и запуск:
   ```bash
   python agent.py --check      # «Связь есть. Устройство: …»
   python agent.py              # работает, пока открыт терминал; остановка — Ctrl+C или «Выход» в трее
   ```

## Пауза
Значок ActivityMind появляется в области уведомлений (рядом с часами). Щелчок по нему или пункт **«Пауза»** останавливает учёт: текущая сессия закрывается, новые не записываются, а на сайте в «Активность → Сейчас» видно «учёт на паузе». **«Продолжить»** возобновляет учёт. Без значка (`--no-tray` или нет пакетов `pystray`/`Pillow`) агент работает в консоли, как раньше.

## Демо без ожидания
Сгенерировать правдоподобную историю за 14 дней и сразу отправить на сайт (работает на любой ОС):
```bash
python agent.py --simulate-days 14
```
Повторный запуск дублей не создаёт. После этого откройте на сайте **Аналитика → Топ приложений**.

## Автозапуск при входе в Windows
Планировщик заданий (без окна консоли):
```bat
schtasks /Create /SC ONLOGON /TN "ActivityMindAgent" /TR "pythonw C:\путь\к\desktop-agent\agent.py" /RL LIMITED
```
Удалить: `schtasks /Delete /TN "ActivityMindAgent" /F`. Журнал — `agent.log` рядом с агентом.

## Настройки (`config.ini`)
| Параметр | По умолчанию | Смысл |
|---|---|---|
| `poll_interval_sec` | 5 | как часто проверять активное окно |
| `idle_threshold_sec` | 300 | через сколько секунд без мыши и клавиатуры считать простоем |
| `min_session_sec` | 3 | более короткие сессии отбрасываются |
| `max_session_sec` | 3600 | длинные сессии режутся на части |
| `track_window_titles` | false | отправлять ли заголовки окон всех программ |
| `track_browser_tabs` | true | отправлять ли названия вкладок браузера, на которых провели не меньше `min_tab_sec` |
| `min_tab_sec` | 300 | сколько секунд непрерывно нужно провести на вкладке, чтобы её название ушло на сайт |
| `ignore_apps` | KeePass, 1Password, Bitwarden | приложения, которые не записываются совсем |
| `interval_sec` / `batch_size` / `timeout_sec` | 60 / 200 / 10 | параметры отправки |

## Что именно отправляется
Для каждой сессии: имя программы (например, `Code`, `chrome`), время начала (UTC), длительность, признак простоя и — **только если включено** — заголовок окна.

Браузер: каждая вкладка — отдельная сессия. Категорию вкладки (учёба, программирование, работа, отдых) агент определяет **на компьютере** по её названию (`browser.py`) и отправляет только категорию. Название вкладки уходит на сайт, лишь если на ней провели непрерывно не меньше 5 минут (`min_tab_sec`); имя браузера и профиля из названия убираются. Сайт дополнительно не хранит названия вкладок короче 5 минут.

Раз в минуту агент сообщает сайту своё состояние: на паузе ли учёт и какая программа открыта сейчас (без заголовка). Содержимое окон, нажатия клавиш, скриншоты и файлы **не собираются**. Данные можно удалить на сайте: **Устройства → Удалить** (вместе с собранной активностью).

## Как это устроено
| Модуль | Роль |
|---|---|
| `tracker.py` | замеры Windows: активное окно, процесс, время простоя (`ctypes`) |
| `session_builder.py` | поток замеров → сессии (смена окна, простой с момента последнего ввода, «сон» компьютера, нарезка длинных) |
| `browser.py` | распознавание браузера, очистка названия вкладки, категория вкладки по ключевым словам |
| `control.py`, `tray.py` | пауза/продолжение/выход, значок в трее |
| `instance_lock.py` | запрет второй копии агента |
| `storage.py` | буфер SQLite, защита от дублей, очистка отправленного |
| `sync_client.py` | HTTP-клиент, разбор ответов `200` / `401` / `422` / сбои сети |
| `agent.py` | цикл работы, что отправлять (`prepare`), состояние для сайта, отправка с нарастающей паузой при ошибках, `--check`, `--simulate-days` |
| `simulate.py` | детерминированная демо-история |

Простой распознаётся, когда без ввода прошло `idle_threshold_sec` секунд, но начинается он с момента последнего ввода: эти минуты не записываются как работа в программе, открытой перед перерывом.

## Тесты
```bash
python -m unittest discover -s tests -v
```
Покрыты разбиение на сессии (включая начало простоя), вкладки браузера и их категории, решение, что отправлять, пауза и остановка в основном цикле, запрет второй копии, обновление старого буфера, клиент API, отправка (успех, обрыв сети, отозванный токен, частичный отказ), конфиг и демо-режим. Сбор данных Windows (`tracker.py`) проверяется вручную: запустить агент, поработать пару минут и посмотреть **Аналитика → Топ приложений**.

## Неполадки
| Симптом | Решение |
|---|---|
| `Не найден config.ini` | скопируйте `config.example.ini` в `config.ini` |
| `Сервер не принял токен (401)` | токен неверный или перевыпущен: создайте новый на сайте |
| `Сайт недоступен` | запущен ли `php artisan serve`; верный ли `url` и порт |
| `Сбор активности работает только в Windows` | запускаете не на Windows; для демо — `--simulate-days` |
| `Агент уже запущен на этом компьютере` | агент уже работает (значок в трее); закройте его через «Выход» |
| Нет значка в трее | установите зависимости: `pip install -r requirements.txt` |
| API отвечает 404 | на сайте не подключён `routes/api.php` (см. README этапа 8) |

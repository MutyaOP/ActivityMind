# ActivityMind Desktop Agent

Небольшая программа для Windows: раз в несколько секунд смотрит, какое приложение активно, собирает это в сессии и отправляет на сайт ActivityMind. Данные попадают в аналитику («Топ приложений», отслеживаемое время).

- Python 3.9+, из внешних библиотек только `requests` (сбор данных — на стандартном `ctypes`)
- локальный буфер SQLite: без сети данные не теряются и уходят позже
- приватность по умолчанию: **заголовки окон не отправляются**

## Установка
1. На сайте: **Устройства → Создать и получить токен** (токен показывается один раз).
2. В этой папке:
   ```bash
   pip install -r requirements.txt
   copy config.example.ini config.ini
   ```
3. В `config.ini` впишите `url` сайта (например, `http://localhost:8000`) и `token`.
4. Проверка связи и запуск:
   ```bash
   python agent.py --check      # «Связь есть. Устройство: …»
   python agent.py              # работает, пока открыт терминал; остановка — Ctrl+C
   ```

## Демо без ожидания
Сгенерировать правдоподобную историю за 14 дней и сразу отправить на сайт (работает на любой ОС):
```bash
python agent.py --simulate-days 14
```
Повторный запуск дублей не создаёт. После этого откройте на сайте **Аналитика → Топ приложений**.

## Автозапуск при входе в Windows
Планировщик заданий (без окна консоли):
```bat
schtasks /Create /SC ONLOGON /TN "ActivityMindAgent" /TR "pythonw C:\путь\к\desktop-agent\agent.py" /RL LIMITED
```
Удалить: `schtasks /Delete /TN "ActivityMindAgent" /F`. Журнал — `agent.log` рядом с агентом.

## Настройки (`config.ini`)
| Параметр | По умолчанию | Смысл |
|---|---|---|
| `poll_interval_sec` | 5 | как часто проверять активное окно |
| `idle_threshold_sec` | 300 | через сколько секунд без мыши и клавиатуры считать простоем |
| `min_session_sec` | 3 | более короткие сессии отбрасываются |
| `max_session_sec` | 3600 | длинные сессии режутся на части |
| `track_window_titles` | false | отправлять ли заголовки окон |
| `ignore_apps` | KeePass, 1Password, Bitwarden | приложения, которые не записываются совсем |
| `interval_sec` / `batch_size` / `timeout_sec` | 60 / 200 / 10 | параметры отправки |

## Что именно отправляется
Для каждой сессии: имя программы (например, `Code`, `chrome`), время начала (UTC), длительность, признак простоя и — **только если включено** — заголовок окна. Содержимое окон, нажатия клавиш, скриншоты и файлы **не собираются**. Данные можно удалить на сайте: **Устройства → Удалить** (вместе с собранной активностью).

## Как это устроено
| Модуль | Роль |
|---|---|
| `tracker.py` | замеры Windows: активное окно, процесс, время простоя (`ctypes`) |
| `session_builder.py` | поток замеров → сессии (смена окна, простой, «сон» компьютера, нарезка длинных) |
| `storage.py` | буфер SQLite, защита от дублей, очистка отправленного |
| `sync_client.py` | HTTP-клиент, разбор ответов `200` / `401` / `422` / сбои сети |
| `agent.py` | цикл работы, отправка с нарастающей паузой при ошибках, `--check`, `--simulate-days` |
| `simulate.py` | детерминированная демо-история |

Простой считается по времени без ввода: первые `idle_threshold_sec` секунд бездействия записываются как работа в текущем приложении — это сознательное упрощение.

## Тесты
```bash
python -m unittest discover -s tests -v
```
Покрыты разбиение на сессии, буфер, клиент API, отправка (успех, обрыв сети, отозванный токен, частичный отказ), конфиг и демо-режим. Сбор данных Windows (`tracker.py`) проверяется вручную: запустить агент, поработать пару минут и посмотреть **Аналитика → Топ приложений**.

## Неполадки
| Симптом | Решение |
|---|---|
| `Не найден config.ini` | скопируйте `config.example.ini` в `config.ini` |
| `Сервер не принял токен (401)` | токен неверный или перевыпущен: создайте новый на сайте |
| `Сайт недоступен` | запущен ли `php artisan serve`; верный ли `url` и порт |
| `Сбор активности работает только в Windows` | запускаете не на Windows; для демо — `--simulate-days` |
| API отвечает 404 | на сайте не подключён `routes/api.php` (см. README этапа 8) |
